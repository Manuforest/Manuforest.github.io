写好以后，怎样发布？

1. 将头部 draft: true 改成 draft: false，检查标题和日期。2. 下载文章包并解压。3. 打开上方上传页，把解压得到的文章文件夹拖进去并提交到 main；自动构建通过后更新网站。直接上传 ZIP 不会发布。

新建草稿不会清除已下载的文件。草稿和图片仅保存在当前浏览器；清除网站数据会丢失它们，请定期导出。仓库是公开的：draft 只控制网站展示，提交到 GitHub 的草稿仍然公开。

这是本地写作工具，不是带登录的 CMS。页面不接收 GitHub Token，也不代你执行提交。图片跟着 Markdown 留在仓库里。
